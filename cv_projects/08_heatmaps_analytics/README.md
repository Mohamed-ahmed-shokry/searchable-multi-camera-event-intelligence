# Subproject 08 — Heatmaps and Analytics (`cv_projects/08_heatmaps_analytics/`)

Visual and statistical summary of scene activity: 2D trajectory density accumulation, Gaussian smoothing, reference-frame heatmap overlay (`heatmap.png`), per-zone counts (`zone_counts.csv`), per-line directional counts (`line_counts.csv`), track duration distributions, and structured activity summary (`analytics_summary.json`).
